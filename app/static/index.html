MTGA collection (optional)

How to export your collection from MTGA
  1. Start MTG Arena and open the Decks tab. Leave Arena running.
  2. Install the MTGA collection exporter (MTGA_Exporter.exe or python mtg.py). Run as Administrator if needed.
  3. On first run, enter at least 3 cards you own with exact quantities (5 rares/mythics recommended).
  4. Upload mtga_collection_moxfield.csv (or Goldfish/Cardsphere CSV from the same export).
  5. If the scan fails: stay on Decks, recheck anchor quantities, try different anchors, or increase --scan-range.
